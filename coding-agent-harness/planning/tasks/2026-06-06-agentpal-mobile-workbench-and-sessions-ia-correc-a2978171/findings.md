# AgentPal mobile workbench and sessions IA correction - 发现记录

本文件记录任务执行中形成的判断、事实和技术决策。它不是审查报告；阻塞性问题请写入 `review.md`。

## 研究发现

### 页面职责重复

- 背景：用户截图显示 `待处理` 和 `会话` 页面都在展示 session 列表，移动端信息架构不清晰。
- 发现：工作台应处理“现在是否需要用户介入”，会话页应按项目/工作区浏览和恢复 session。
- 影响：本轮移除工作台完整 session 列表，并移除会话页 Host 大卡和指标卡。
- 后续：用户真机确认后再决定是否继续调整会话页密度。

### 项目名称显示

- 背景：会话页项目分组中出现 `.`，手机端无法理解。
- 发现：`.` 是相对工作区标识，不适合作为项目名直接展示。
- 影响：`compactWorkspaceName` 将空值、`.`、`unknown-workspace` 映射成“当前项目”，`displayWorkspacePath` 映射成可读路径说明。
- 后续：后端如果能返回绝对 workspace，应优先使用真实路径。

## 技术决策

| 决策 | 选择 | 原因 | 替代方案 | 状态 |
| --- | --- | --- | --- | --- |
| 顶层导航 | 工作台 / 会话 / 设置 | 对应用户核心任务：处理关注事项、恢复 session、管理连接和偏好 | 保留“待处理 / 会话 / 设置” | accepted |
| 会话页结构 | 按项目卡分组 session | 对齐 Codex desktop 的 project -> session 模型，同时适配手机纵向浏览 | 全局扁平 session 列表 | accepted |
