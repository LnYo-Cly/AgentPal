# AgentPal mobile workspace session browser redesign - 发现记录

本文件记录任务执行中形成的判断、事实和技术决策。它不是审查报告；阻塞性问题请写入 `review.md`。

## 研究发现

### Codex 桌面端项目侧栏不应原样搬到手机

- 背景：用户提供了 Codex 桌面端截图，显示左侧 `项目` 下挂多个会话，并询问这对 AgentPal 手机端设计是否有参考价值。
- 发现：Codex 桌面端最值得学习的是信息关系：`项目/工作区 -> sessions -> 当前会话`，不是桌面左侧栏布局本身。
- 影响：手机端底部 `会话` 应成为项目分组 session 浏览器；当前会话详情内的目录树不能继续叫 `项目`，应改为 `文件`。
- 后续：真实新建 session、搜索和多 Host 聚合可在该结构上继续扩展。

## 技术决策

| 决策 | 选择 | 原因 | 替代方案 | 状态 |
| --- | --- | --- | --- | --- |
| 全局 `会话` 页 | 项目/工作区分组 session 浏览器 | 匹配 Codex 桌面端的项目下挂会话模型，并适合移动端纵向浏览 | 继续让 `会话` 直接进入当前会话详情 | accepted |
| 会话详情分段 | `聊天 / 文件 / 变更` | 避免 `项目` 同时表示 session 容器和文件目录树 | `聊天 / 项目 / 变更` | accepted |
| 后端协议 | 本任务不新增协议 | 当前 sessions 已带 workspace，可先完成移动端信息架构 | 立即实现 Host 真实新会话和全局 session 扫描 | accepted |
